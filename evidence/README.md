# Evidence

One folder per task, `<issue>-<slug>/`, written by `npm run evidence -- <issue>-<slug>` from
the matching spec in [`tests/evidence/`](../tests/evidence/). Each holds the task's
screenshots at desktop and phone widths and a generated `README.md` listing every check and
whether it passed. The rules are in [docs/evidence.md](../docs/evidence.md).
