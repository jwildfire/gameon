README opening

GameOn turns a spoken game idea into a playable browser game in about an hour. Describe it, an AI agent builds it, a person checks it, and it joins the arcade, with versions, so anyone can remix a game they like.

For kids: completely safe, a little dry. A kid can use it fine but won't grin at it.

Mixing them

  • My pick is A, Game Night. It says couch co-op without saying it, it reads naturally to an adult, and it's still friendly for a seven-year-old.
  • A good blend: A's words everywhere, with B's arcade flavour in small doses. For example, "Game on!" as the published status, and "Press Start" only on controller hints once controller support lands.
  • Credits drop "designed by a 4-year-old" and "designed with my kids" for a plain "Made by {nickname}", with ages only where you want them. The nickname is also the version name (jeremy.v2), so it lines up.
  • Whichever you pick, I'll rewrite the arcade, the New Game page, the README and the docs intro to match. Agent-facing files (AGENTS.md, skills) keep plain instructions, with the kid-safety rules unchanged.
