GameOn design · Weird mode ideas (#142)

Weird mode, next

Weird mode ships in v0.3 as a costume for the arcade: trippy backgrounds, random taglines and a shuffle button. The games themselves don't notice. This doc collects ideas for more weirdness, lays out four ways Weird could change how games play, and adds two of Jeremy's ideas: a dropdown of modes (Weird, Fun, Silly, Calm) and vibe scores on every game.

Where we are

What Weird does in v0.3

  • A Normal | Weird switch in the arcade header, remembered per browser (gameon.arcade.mode) and settable with ?mode=weird.
  • Weird: ten animated backgrounds (Matrix Rain, Rainbow Plasma, Hypno Spiral, Tie-Dye and friends) cycling every few seconds, plus a tagline that rotates through 53 lines. Twenty more backgrounds are being built tonight (#141).
  • Normal: a plain colored wall and the fixed tagline "Think of a Game? Make it, play it, change it!"
  • A shuffle button in the bottom-right corner. In Weird it jumps to a random background; in Normal it picks a new wall pattern.
  • Safety already built in: no fast flashing, a still frame for reduced motion, backgrounds pause while a game is open, and phones are capped at 30 frames a second.

The mode is already a single attribute (<html data-mode>) and an event (gameon:mode). Everything below builds on those two hooks.

The big question

Four ways Weird could change gameplay

Jeremy wants Weird to affect how games play eventually. The options form a ladder: each rung costs more and changes more. They aren't exclusive. The recommendation is to climb them in order.

  1. A

    Effects on the game window Start here

    No changes to any game

    The arcade already shows each game in a frame. In Weird mode, the arcade can bend that frame: a slow color drift (hue rotation), a gentle wobble, a mirror flip, a squash-and-stretch bounce, chunky pixels. It works on all nine games tomorrow.

    Cost
    One PR to the arcade player. A few CSS filters and transforms, plus a picker in the player bar.
    Limits
    It changes the look, never the rules. A mirror flips text and controls, which is the joke but confuses little kids, so it's opt-in.
    Watch for
    Phone speed (filters on a game frame are costly; test on a real phone) and motion sickness: no wobble with reduced motion.
  2. B

    A small mutator contract Pilot next

    Games opt in, one at a time

    The arcade tells each game which mode is on and which mutators are active. A game that knows about them changes its own physics or art. Games that don't simply ignore them.

    // arcade opens the game with
games/trampoline-battle/jeremy.v2/?mode=weird&mods=lowgrav,bighead

// a tiny shared helper the game includes
if (GameOn.mods.has("lowgrav")) gravity *= 0.4;
document.addEventListener("gameon:mods", e => restyle(e.detail));

    A standard menu keeps it simple. Each game lists the ones it supports in games.json ("mods": ["lowgrav", "bighead"]), and the player bar only offers those.

    MutatorWhat changesFits
    lowgravGravity at 40%. Floaty jumps.Trampoline Battle, Super Sauce Boy, Angry Dudes
    bigheadCharacters get giant heads; hit boxes stay the same.Any game with characters
    tinyEveryone is half size.Platformers, MazeAThon

    Cost
    One shared helper (assets/gameon-mods.js), then a small update per game. The build skill adds two or three mutators to every new game by default.
    Limits
    Mutators change feel, never unlock content or save anything. The frozen version stays the same; the flag only applies while it's on.
    Ties in
    This is the same plumbing the couch co-op kit (#131) needs for controllers and player counts. Build it once.
  3. C

    Weird versions from the pipeline Let it happen

    Uses the version system we already have

    A kid sends an update idea, "Trampoline Battle but on the moon with cats," and the pipeline builds it as a new version tagged weird. In Weird mode the arcade opens the weird version by default when one exists; in Normal it opens the regular one.

    Cost
    A "vibe" tag on versions and one rule in the arcade. The builds come through the normal idea flow.
    Limits
    Versions drift apart: a fix to the regular game doesn't reach the weird one. Fine for one-off jokes, bad for games we keep improving.
    Best for
    Kids' wild ideas that rewrite a game. No contract needed.
  4. D

    Couch co-op chaos events Later, with #132

    Party-game moments built on B

    Every 30 to 60 seconds in a multiplayer game, a banner counts down "3… 2… 1… GRAVITY FLIP!" and a mutator switches on for ten seconds. Others: swap sides, everyone huge, slow-mo, lights off with flashlights. This is the Mario Party and Overcooked feeling that makes grown-ups and kids yell at the couch.

    Cost
    An event timer in the shared helper, plus game support for the mutators it fires.
    Limits
    Always warned three seconds ahead, short, fair to every player, one at a time, and off in Calm.
    Best for
    The first couch co-op game (#132), designed with chaos events from day one.

Jeremy's idea

A dropdown of modes

"Maybe people can pick other modes in a dropdown with weird. fun. silly. calm." The Normal | Weird switch becomes a mode picker. Each mode is a bundle: a background set, a tagline set, sounds, which window effects and mutators it may turn on, and which games float to the top of the list.

NormalPlain wall; shuffle picks a patternThe fixed oneNothing changesNewest first (today's order)
WeirdTrippy shaders: Matrix, plasma, spiralsRandom strange linesWobble, hue drift, lowgrav, mirror, chaos eventsWeird score
FunBright confetti, party colorsHype-man lines ("Rematch!")Sounds on, confetti, fastFun score
SillyBouncy cards, googly eyes, goofy fontsJokes and punsbighead, bouncy, squeaky soundsSilly score
CalmSlow soft gradients, no fast motionGentle linesslowmo, no timers where a game allows, no chaos eventsCalm score
  • On a phone the picker is a native dropdown; on a wide screen it can stay a row of buttons. The shuffle button keeps working inside any mode.
  • Code: mode.js already treats the mode as a word on <html>. Adding modes means a small registry (backgrounds, taglines, allowed effects per mode) and widening the one check that only accepts "normal" or "weird".
  • Calm and reduced motion fit together. A browser that asks for reduced motion could start in Calm instead of getting a still frame of Weird.
  • Games read the same word through rung B, so a game can tune itself per mode without knowing about the arcade.

Jeremy's other idea

Vibe scores on every game

"Maybe we just classify the games based on how weird fun etc they are and surface those in list somehow." Give each game a score from 0 to 3 on the same four words as the modes. Then the modes and the games speak one language: picking a mode changes how the arcade looks and which games come first.

// games.json, per game
"vibe": { "weird": 1, "fun": 3, "silly": 2, "calm": 0 }
  • Who scores: the evaluate skill drafts scores for every new idea, the same way it scores fun and safety today. A person (or a kids' vote) can change them in the issue.
  • Showing it: four small dot meters on each card, filter chips above the list ("Calm games"), the mode's sort order, and a Surprise me button weighted by the mode.
  • Existing games: the scores below are first guesses for the kids to argue about. Play with the dropdown to see the sort.
Normal keeps today's order.

    Draft scores, not measured. Games scoring 0 on the mode's word are dimmed rather than hidden, so nothing disappears from the list.

    Ground rules

    Safety limits for every mode

    • No flashing faster than three times a second, in backgrounds, effects or chaos events.
    • Reduced motion means no wobble, no tilt, no fast motion; start in Calm or show a still frame.
    • Effects never cover the controls or the text a player needs to read.
    • Mirror and upside-down are opt-in, never a mode's default.
    • Sounds only after a tap, always with a mute that's one tap away.
    • Chaos events are warned three seconds ahead, last about ten seconds, and never fire in Calm or single-player games.
    • Normal stays truly normal: no effects, no mutators. Getting back to Normal is always one tap.
    • Mutators never change a saved game or a frozen version. They live only while switched on.

    Recommendation

    What to build, in order

    1. Mode dropdown with Normal, Weird and CalmCalm is cheap (slow backgrounds, gentle taglines) and pairs with reduced motion. Fun and Silly follow once their backgrounds and taglines exist.
    2. Vibe scores in games.jsonDots on the cards, filter chips, and sorting by the current mode. The evaluate skill starts drafting scores for new ideas.
    3. Effects on the game window (A)A small picker in the player bar for Weird and Silly. Every game gets something weird with no rebuilds.
    4. Mutator contract (B), piloted on Trampoline BattleThree mutators in one two-player game, then folded into the couch co-op kit (#131) so new games get them for free.
    5. Chaos events (D) in the first co-op gameDesigned in from the start with #132. Weird versions (C) keep arriving through the idea form whenever a kid asks.

    For Jeremy and Ryan

    Questions

    1. Which modes go in the first dropdown?Recommend Normal, Weird and Calm first, then Fun and Silly. Or all five at once with thinner Fun and Silly sets?
    2. Should switching mode change the games on its own?Recommend yes for supported games, with a "Normal game" toggle in the player bar. The other choice is off until a player taps "Make it weird".
    3. Who sets vibe scores?Recommend the evaluator drafts, kids vote to change. The vote could be a reaction on the game's issue.
    4. Are mirror controls too mean for the little kids?Recommend keeping mirror and upside-down opt-in only, never part of default Weird.
    5. Should reduced-motion browsers start in Calm?Recommend yes. They get a mode built for them instead of a frozen Weird background.
    6. Which mode should a first-time visitor see?Today it's Normal. Weird is the more surprising first impression; Normal is easier to read.
