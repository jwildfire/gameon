# Designs and artifacts

Everything worth keeping that isn't code lives in [`artifacts/`](../artifacts/README.md),
one folder per item, named `<YYYY-MM-DD>-<slug>/`. Folder names are permanent: issues, PRs
and live pages link to them, so never move or rename one.

HTML designs are best read on the site, where they render; the "view" links below go
there. Reports are Markdown and read fine on GitHub.
